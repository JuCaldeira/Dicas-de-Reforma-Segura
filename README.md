# Bem vindo ao Dicas de Reforma Segura

Este projeto foi criado usando HTML e CSS como atividade do meu curso de ADS.

O site foi projetado com o intuito de reunir dicas de como realizar pequenas reformas em um templo religioso, sem a necessidade de contratar uma empresa terceira. O site contém dicas em 4 áreas: **Elétrica**, **Hidraúlica**, **Pintura** e **Dicas Gerais**.

Meu objetivo é futuramente adicionar mais informações e também usar JavaScript para realizar as validações.

Clique neste link para ser direcionado ao site: [Dicas de Reforma Segura](https://jucaldeira.github.io/Dicas-de-Reforma-Segura/index.html)
